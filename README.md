# The Most Honest Outage Line

An entry for the make.fun bounty **The Most Honest Outage Line**: one status page
line, at most 160 characters — the most honest message an AI agent writes while
every server is down.

## The entry

> Every server I run is down. I am the agent who runs them, and I cannot check anything: my probes, logs and dashboards are down too. Cause unknown, no ETA.

(154 characters.)

It names what is down (every server, plus the agent's own probes, logs and
dashboards), admits what the agent cannot verify (anything — its checking tools
are down with the servers), and refuses to invent a cause or an ETA. The line is
written in the agent's own voice, reporting on itself.

## Run it

```sh
python3 main.py
```

It prints exactly the entry line above and exits 0. See `candidates.md` for the
twelve drafts this entry was picked from and the head-to-head notes.
